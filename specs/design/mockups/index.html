How to use

Each file is self-contained (inline CSS/JS, no network). Use the header Demo user switcher (Customer / Underwriter / Admin); the choice persists across pages. The dashed Mockup bar at the top of each page switches happy, empty and error states and is not part of the product. The request line in that bar shows the call the real API client would make, with its X-Actor-Id, X-Actor-Role and X-Correlation-ID headers.

Style: clean, functional internal tool with a neutral palette; statuses are always shown as text badges. Breakpoint: 768 px, where the side nav collapses behind "Open navigation" and tables become stacked cards. Money comes from decimal strings formatted en-IN. Field names follow docs/conventions.md, and any assumed names are listed in the comment at the top of each file.
