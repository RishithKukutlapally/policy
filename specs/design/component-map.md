# Component Map — Story → Files

Produced by `/design` (planner). Routing table for `/build` / `/implement`: for each of the 34 stories, the exact
files it **creates (C)** or **modifies (M)** — production and test — plus its sprint and parallel group from
`specs/stories/dependency-graph.md`. Paths are relative to the repo root. Module names follow `docs/conventions.md`;
the tree is in [`folder-structure.md`](folder-structure.md), tables and migrations in [`data-models.md`](data-models.md).

Test naming: AC tests live in `backend/tests/ac/test_acNN_<topic>.py`, each test `test_acNN_<behaviour>` with
`@pytest.mark.ac("AC-NN")`. Criteria without an AC id (`[—]`) are covered by `unit/`, `integration/` or
`architecture/` tests. Frontend unit tests are co-located `*.test.ts(x)` (vitest). Playwright titles carry `AC-NN`.

Abbreviations inside cells: `be/` = `backend/`, `src/` = `backend/src/`, `fe/` = `frontend/src/`, `t/` = `backend/tests/`,
`mig/` = `backend/migrations/versions/`, `rules/` = `backend/policy_rules/`.

1. **E6-S1 missing dependency on E5-S1.** E6-S1 AC-5 delegates terminal-status checks to the E5-S1 state machine
   (`InvalidPolicyStateException`), while both sat in parallel group S3-A.
   **Resolved (DEC-014):** E6-S1 depends on `E3-S1, E5-S1` and moves to S3-B.

   (E7-S1 `renewal_premium`/`advance_inputs`) and AC-3 evaluates E7-S1 `renewal_action`.
   **Resolved (DEC-014):** E7-S2 depends on `E5-S2, E7-S1` and moves to S4-B; E7-S3 (which needs E7-S2) moves to S4-C.

   with endorsement and refund rows "via the services".
   **Resolved (DEC-014):** E9-S3 depends on `E5-S2, E6-S2, E7-S3, E8-S2`. Because E7-S3 lands in S4-C, E9-S3 runs in
   **S4-D** (one group later than DEC-014's note, which assumed E7-S3 stayed in S4-B); the later groups shift to
   S4-D (E7-S4, E9-S1, E9-S3), S4-E (E9-S2), S4-F (E9-S4).

   E6-S2/E8-S2 add only the writing services (see data-models §8-C6).

   `POLICYFORGE_BUSINESS_DATE`, unset = real today) in `src/config/settings.py`, read by every layer through
   `src/lib/clock.py::today()`; recorded in `docs/conventions.md` → Settings. E6-S3 AC-4 and E7-S4 AC-6 now name
   the setting explicitly, and E1-S4 AC-6 is the architecture test that forbids `date.today()` / `datetime.now()`
