# E8-S3 — Cancel API + UI with refund preview

- **ID:** E8-S3
- **Epic:** E8 — Cancellation & refunds
- **Layer:** UI
- **Group:** S4-C
- **Sprint:** 4
- **Depends on:** E8-S2, E5-S3
- **Traces:** AC-08, AC-19, AC-10, AC-22, AC-24

## Description

Expose `GET /api/policies/{policy_number}/cancellation-preview?date=YYYY-MM-DD` and
`POST /api/policies/{policy_number}/cancel` in `src/api/routers/cancellations.py`, and build the customer
**Cancel** screen: pick a cancellation date, see the refund preview with its breakdown (free-look or pro-rata,
unused days, admin fee), confirm, and land on Policy Detail showing `CANCELLED` and the refund.

## Acceptance Criteria

1. [AC-08] `POST /api/policies/TL-2026-000001/cancel` by the owning CUSTOMER with `{"cancellation_date": "2026-04-01", "reason": "Vehicle sold"}` returns 200 with `status: "CANCELLED"`, `refund.reason: "Vehicle sold"` (free text ≤ 200 chars), `refund.amount: "8791.10"` and `refund.refund_type: "PRO_RATA"` _(category: integration)_
   - Verify: POST with the owner's headers; assert 200 and the body fields; GET the policy and assert status `CANCELLED`
2. [AC-19] `GET /api/policies/TL-2026-000001/cancellation-preview?date=2026-01-10` returns 200 with `amount: "12000.00"`, `refund_type: "FREE_LOOK"`, `admin_fee: "0.00"` and writes nothing _(category: functional)_
   - Verify: GET the preview; assert 200 and fields; assert the `refunds` row count and policy status are unchanged
3. [AC-10] Cancelling an already `CANCELLED` policy returns 409 with error code `INVALID_POLICY_STATE`; a date outside the policy term returns 422 `VALIDATION_ERROR` (`OUTSIDE_TERM`); another customer's policy returns 404 `NOT_FOUND`; missing `X-Actor-Id` returns 401 `UNAUTHENTICATED` _(category: security)_
   - Verify: POST a second cancel and assert 409; POST with `cancellation_date: "2027-01-01"` and assert 422; POST as cust-002 and assert 404; POST without headers and assert 401
4. [AC-19] The Cancel screen shows the preview formatted `en-IN` (e.g. `Refund ₹8,791.10 = ₹9,041.10 pro-rata for 275 unused days − ₹250.00 admin fee`, or `Full refund ₹12,000.00 (free-look)`) and updates when the date changes; "Confirm cancellation" requires an explicit confirmation dialog _(category: ui)_
   - Verify: in Playwright as the Customer demo user open `/policies/TL-2026-000001/cancel`; set date `2026-01-10` and assert `Full refund ₹12,000.00`; set `2026-04-01` and assert `₹8,791.10`; click confirm and assert a dialog before submission
5. [AC-24] After confirming, Policy Detail shows badge `CANCELLED` and a refund row; the Cancel screen is usable at 390 px with keyboard only _(category: ui)_
   - Verify: confirm cancellation and assert URL `/policies/TL-2026-000001`, badge `CANCELLED` and a refund row with `₹8,791.10`; repeat on a fresh policy at viewport 390×844 using only keyboard input and assert the same outcome
