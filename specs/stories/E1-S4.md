# E1-S4 — Architecture tests + import-linter contracts

- **ID:** E1-S4
- **Epic:** E1 — Platform foundation
- **Layer:** Types
- **Group:** S1-B
- **Sprint:** 1
- **Depends on:** E1-S1
- **Traces:** NFR-08, NFR-01, NFR-02

## Description

Encode the architecture rules as executable tests in `backend/tests/architecture/` plus import-linter contracts,
so layering, domain purity, fixed-point money, append-only repositories and immutable published rule files
are enforced on every `uv run pytest` run and in CI rather than by review alone.

## Acceptance Criteria

1. [—] Import-linter contracts encode the one-way layer rules from `docs/conventions.md` (types → nothing; domain → types; config → types, domain; repository → types, config; service → types, domain, config, repository; api → types, config, service — never repository); `uv run lint-imports` exits 0 on the codebase _(category: security)_
   - Verify: run `uv run lint-imports` and assert exit 0; in a temp copy add `from src.repository import models` to a file in `src/api/routers/`; assert `lint-imports` exits non-zero naming the broken contract
2. [—] `test_domain_purity` fails if any module in `src/types/` or `src/domain/` imports `logging`, `src.lib`, `sqlalchemy`, `open`, `datetime.now`/`date.today` or `time` _(category: security)_
   - Verify: run the test on the codebase and assert pass; inject `import logging` into a temp domain module; assert the test fails and names that module
3. [—] `test_no_float_in_money_code` scans `src/domain`, `src/service` and `src/repository` with `ast` and fails on any `float(` call, `float` annotation or float literal assigned to a name containing `premium`, `refund`, `sum_insured` or `fee` _(category: security)_
   - Verify: run the test and assert pass; add `premium: float = 1.5` to a temp service module; assert failure naming file and line
4. [—] `test_published_rule_files_unchanged` recomputes SHA-256 of every file listed in `backend/policy_rules/PUBLISHED.lock` and fails if any hash differs or a listed file is missing _(category: security)_
   - Verify: run the test and assert pass; change one byte of `motor/v1.json` in a temp copy; assert the test fails naming `motor/v1.json`
5. [—] `test_append_only_repositories` fails if a repository for any append-only table (`rule_set_versions`, `underwriting_decisions`, `underwriting_overrides`, `policy_state_transitions`, `endorsements`, `premium_payments`, `refunds`, `audit_records`) exposes a public method whose name starts with `update`, `delete`, `remove` or `set` _(category: security)_
   - Verify: run the test and assert pass; add `def delete(self, id)` to a temp append-only repository; assert the test fails naming the class and method
6. [—] `test_business_date_only_from_clock` scans every module under `backend/src/` with `ast` and fails if any module other than `src/lib/clock.py` calls `date.today()`, `datetime.now()`, `datetime.utcnow()` or `datetime.today()` — "today" is read only through `src/lib/clock.py::today()`, which honours the `business_date` setting (DEC-012) _(category: security)_
   - Verify: run the test on the codebase and assert pass; add `date.today()` to a temp module in `src/service/`; assert the test fails naming that file and line; assert `src/lib/clock.py` itself is exempt
