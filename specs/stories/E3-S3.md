# E3-S3 — Quote API + Get-a-Quote UI

- **ID:** E3-S3
- **Epic:** E3 — Quote engine
- **Layer:** UI
- **Group:** S2-C
- **Sprint:** 2
- **Depends on:** E3-S2, E1-S5
- **Traces:** AC-01, AC-12, AC-13, AC-22, AC-24

## Description

Expose quoting in `src/api/routers/quotes.py` (`POST /api/quotes`, `GET /api/quotes/{quote_id}`) for the
`CUSTOMER` role and build the "Get a Quote" screen at `/quote`: pick a product, fill the product-specific risk
form, see the premium in INR (`en-IN` formatting) with the rule version, and continue to Apply.

## Acceptance Criteria

1. [AC-01] `POST /api/quotes` as CUSTOMER with body `{product: "MOTOR", inputs: {owner_age: 30, sum_insured: "500000.00", vehicle_age_years: 3, engine_cc: 1200, zone: "A", ncb_percent: "20"}}` returns 201 with `{quote_id, product: "MOTOR", rule_version: 1, premium: "14322.00", currency: "INR"}` — money serialised as a string, never a JSON number _(category: integration)_
   - Verify: POST the body with CUSTOMER headers; assert 201 and each field; assert `isinstance(body["premium"], str)`
2. [AC-12] Invalid input returns 422 `{"error": {"code": "VALIDATION_ERROR", "message": …, "details": [{"field": "sum_insured", "code": "OUT_OF_RANGE"}]}}`; a product with no PUBLISHED version returns 409 with `error.code` `NO_PUBLISHED_VERSION`; in both cases no quote is stored _(category: integration)_
   - Verify: POST MOTOR with sum_insured `"50000.00"` and assert 422 with that error; remove HOUSEHOLD versions in the test DB and POST HOUSEHOLD, asserting 409; assert the `quotes` count is unchanged
3. [AC-13] `GET /api/quotes/{quote_id}` returns 200 with the stored input, `rule_version` and the same premium string; an unknown id returns 404 `NOT_FOUND` _(category: integration)_
   - Verify: create a quote then GET it and assert premium `"14322.00"` and version 1; GET a random UUID and assert 404
4. [AC-22] `POST /api/quotes` without actor headers returns 401 `UNAUTHENTICATED` and as `UNDERWRITER` returns 403 `FORBIDDEN` _(category: security)_
   - Verify: POST with no headers and assert 401; POST with `X-Actor-Role: UNDERWRITER` and assert 403
5. [AC-12] In the UI as Customer, choosing MOTOR shows labelled fields Owner age, Sum insured, Vehicle age (years), Engine cc, Zone, NCB %; submitting the golden input displays "₹14,322.00" and "Rule version v1" plus an "Apply" button; submitting sum insured 50000 shows the inline error on the Sum insured field without a premium _(category: ui)_
   - Verify: Playwright as Customer fills the MOTOR form and submits; assert premium text `₹14,322.00` and `Rule version v1`; resubmit with 50000 and assert an error associated (aria-describedby) with the Sum insured input
6. [AC-24] The Get-a-Quote form is usable at 390 px: fields stack in one column, the submit button is fully visible, no horizontal scroll _(category: ui)_
   - Verify: Playwright at 390×844 opens `/quote` as Customer; assert the submit button is in the viewport after scroll; assert `scrollWidth ≤ 390`
