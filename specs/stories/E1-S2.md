# E1-S2 — Structured JSON logging, correlation-id middleware, PII masking

- **ID:** E1-S2
- **Epic:** E1 — Platform foundation
- **Layer:** Config
- **Group:** S1-B
- **Sprint:** 1
- **Depends on:** E1-S1
- **Traces:** AC-23, NFR-03, NFR-06

## Description

Provide the cross-cutting observability layer: `src/lib/logging.py` (`get_logger`, `mask_pii`) emits one JSON
object per line, `src/lib/correlation.py` holds the per-request correlation id, and `src/api/middleware.py`
reads or generates `X-Correlation-ID` and echoes it on every response. PII (Aadhaar, PAN, health
declarations) is masked before any log record is serialised, so no later story can leak it by accident.

## Acceptance Criteria

1. [AC-23] A request carrying `X-Correlation-ID: test-corr-001` receives the same value in the response `X-Correlation-ID` header; a request without the header receives a freshly generated UUID4 in it — for both 2xx and 4xx responses _(category: functional)_
   - Verify: `GET /health` with header `test-corr-001` and assert the echoed header equals it; `GET /health` without the header and assert the response header parses as a UUID4; `GET /api/does-not-exist` and assert 404 still carries `X-Correlation-ID`
2. [AC-23] Every log line written during a request is a single valid JSON object containing at least the keys `timestamp`, `level`, `logger`, `message` and `correlation_id`, where `correlation_id` equals the request's `X-Correlation-ID` _(category: functional)_
   - Verify: capture stdout while calling `GET /health` with `X-Correlation-ID: test-corr-002`; parse each captured line with `json.loads`; assert all five keys are present and `correlation_id == "test-corr-002"`
3. [AC-23] `mask_pii` masks synthetic PII to last-4 form: `mask_pii("999900000001")` returns `"XXXX-XXXX-0001"` and the PAN `"AAAAA0001A"` is rendered as `"XXXXX0001X"` when embedded in a message string (masked forms per `docs/conventions.md`) _(category: security)_
   - Verify: call `mask_pii` on the Aadhaar string and assert `XXXX-XXXX-0001`; call it on `"pan=AAAAA0001A"` and assert the raw PAN no longer appears and `XXXXX0001X` does; call it on `"no pii here"` and assert unchanged output
4. [AC-23] Logging a record whose message or `extra` contains an Aadhaar, a PAN or a key named `health_declaration` produces a log line with none of the raw values; health-declaration values are replaced by `"[REDACTED]"` _(category: security)_
   - Verify: `get_logger("t").info("kyc", extra={"aadhaar": "999900000001", "pan": "AAAAA0001A", "health_declaration": {"condition": "asthma"}})`; capture output; assert `999900000001`, `AAAAA0001A` and `asthma` are absent and `[REDACTED]` is present
5. [—] `src/lib/logging.py` and `src/lib/correlation.py` import only the Python standard library (no `fastapi`, `sqlalchemy` or `src.*` imports) _(category: security)_
   - Verify: parse both modules with `ast`; collect imported top-level module names; assert each is in `sys.stdlib_module_names`
