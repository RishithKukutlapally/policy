# E9-S1 — Portfolio dashboard service + API

- **ID:** E9-S1
- **Epic:** E9 — Portfolio dashboard, seed & end-to-end
- **Layer:** Service
- **Group:** S4-D
- **Sprint:** 4
- **Depends on:** E7-S3, E8-S2
- **Traces:** AC-20, AC-22, NFR-01

## Description

Implement `src/service/portfolio_service.py` and the admin-only `GET /api/admin/portfolio?as_of=YYYY-MM-DD`
in `src/api/routers/admin.py`. The response aggregates active policies by product, premium collected, refunds
paid, the renewal pipeline (renewal due within the next `renewal_window_days` = 30 days, paid vs unpaid) and
the lapse forecast (unpaid policies whose grace period ends within the same window), all computed with `Decimal`
and an explicit `as_of`.

## Acceptance Criteria

1. [AC-20] `active_by_product` counts policies in `ACTIVE` or `ENDORSED` per product and always lists all three codes: with 3 MOTOR, 2 HOUSEHOLD, 0 TERM_LIFE in force plus 1 CANCELLED and 1 LAPSED MOTOR, it returns `{"TERM_LIFE": 0, "MOTOR": 3, "HOUSEHOLD": 2}` _(category: functional)_
   - Verify: seed the listed policies; call `portfolio_summary(as_of)`; assert the exact dict
2. [AC-20] `premium_collected` = sum of all `PremiumPayment` amounts (first-term payments recorded at issuance + renewal payments), and `refunds_paid` = sum of `Refund` amounts; with first-term payments `12000.00` (TERM_LIFE) + `15500.00` (MOTOR), one renewal payment `15500.00` and one refund `8791.10` it returns `"43000.00"` and `"8791.10"` _(category: functional)_
   - Verify: seed that data; call the service; assert `premium_collected == Decimal("43000.00")` and `refunds_paid == Decimal("8791.10")`; assert both are `Decimal` with exponent `-2`
3. [AC-20] `renewal_pipeline` lists policies whose renewal due date (`expiry_date` + 1 day) falls in `(as_of, as_of + renewal_window_days]` as items `{policy_number, product, due_date, renewal_premium, paid}` (no totals field — the UI sums client-side); `lapse_forecast` lists unpaid policies in grace whose grace end falls in `[as_of, as_of + renewal_window_days]` with count and `premium_at_risk` _(category: functional)_
   - Verify: with `as_of = 2027-01-01` seed policies due `2027-01-15` (paid), `2027-01-20` (unpaid), `2027-03-01` (outside), and one unpaid due `2026-12-20` (grace end `2027-01-19`); assert the pipeline holds the first two with correct `paid` flags and the forecast holds only the last with its premium
4. [AC-22] `GET /api/admin/portfolio?as_of=2027-01-01` returns 200 for `ADMIN` with money as 2-decimal strings; `CUSTOMER` and `UNDERWRITER` get 403, no `X-Actor-Id` gets 401, and a malformed `as_of` gets 422 _(category: security)_
   - Verify: call as each role and without headers and assert 200/403/403/401; call with `as_of=2027-13-01` and assert 422; assert `premium_collected` in the JSON is a string matching `^\d+\.\d{2}$`
5. [—] The endpoint responds in under 500 ms p95 over 20 calls with the E9-S3 seed data loaded _(category: performance)_
   - Verify: load the seed; call the endpoint 20 times with `httpx` timing; assert the 95th-percentile latency is below 500 ms
