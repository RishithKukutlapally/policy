# E4-S4 — Admin queue review + DECLINE override, audited

- **ID:** E4-S4
- **Epic:** E4 — Application & underwriting
- **Layer:** API
- **Group:** S2-E
- **Sprint:** 2
- **Depends on:** E4-S3
- **Traces:** AC-09, NFR-02, NFR-04

## Description

Admins review the manual underwriting queue and may override a `DECLINED` application to `AUTO_BIND` with a
reason code and a mandatory comment. Router `src/api/routers/underwriting.py` serves
`GET /api/underwriting/queue` to ADMIN (MANUAL_REVIEW and DECLINED cases) and
`POST /api/underwriting/applications/{application_id}/override` (ADMIN only), backed by `underwriting_service`. Each override appends an `UnderwritingOverride`
(`underwriting_overrides`, append-only) and an audit record.

## Acceptance Criteria

1. [AC-09] `GET /api/underwriting/queue` as ADMIN returns 200 with all `MANUAL_REVIEW` and `DECLINED` applications, each with `status`, `reason_codes`, `rule_version` and its decision history (SYSTEM and underwriter decisions in order) _(category: integration)_
   - Verify: seed one MANUAL_REVIEW, one DECLINED (SYSTEM) and one DECLINED-by-`uw-001` application; GET as `admin-001`; assert the three ids, statuses and per-case history length
2. [AC-09] `POST .../override` as `admin-001` with `{reason_code: "MO-UW-901", comment: "Vehicle restored and certified roadworthy"}` on a DECLINED MOTOR application returns 200, sets status `AUTO_BIND`, and appends one `underwriting_overrides` row `{application_id, from_status: "DECLINED", to_status: "AUTO_BIND", reason_code, comment, actor_id: "admin-001"}` _(category: functional)_
   - Verify: create a DECLINED MOTOR application (vehicle_age_years 16); POST the override; assert 200, new status and the override row fields
3. [AC-09] Each override writes one `audit_records` row `{actor_id: "admin-001", actor_role: "ADMIN", action: "UW_OVERRIDE_DECLINE", entity_type: "APPLICATION", entity_id: <application_id>}` including the comment in `detail` _(category: security)_
   - Verify: POST the override; query `audit_records` for the application; assert exactly one `UW_OVERRIDE_DECLINE` row with those values
4. [AC-09] Validation: comment shorter than 10 or longer than 500 characters, or a `reason_code` not in the case's rule version `reason_codes`, returns 422 `VALIDATION_ERROR`; overriding an application that is not `DECLINED` (e.g. `MANUAL_REVIEW` or `AUTO_BIND`) returns 409 `INVALID_APPLICATION_STATE`; no override or audit row is written in these cases _(category: functional)_
   - Verify: POST with comment `"ok"` and with reason `HH-UW-001` on a MOTOR case (422 each); POST on a MANUAL_REVIEW case (409); assert `underwriting_overrides` and `audit_records` counts unchanged
5. [AC-09] The override endpoint returns 401 `UNAUTHENTICATED` without actor headers and 403 `FORBIDDEN` for `UNDERWRITER` and `CUSTOMER`, and `GET /api/underwriting/queue?status=DECLINED` returns 403 for `UNDERWRITER`; `UnderwritingOverrideRepository` exposes only `add` and read methods _(category: security)_
   - Verify: call the override with no headers (401), as UNDERWRITER (403) and as CUSTOMER (403); GET the DECLINED queue as UNDERWRITER (403); introspect the repository's public methods
