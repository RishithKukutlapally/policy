# E5-S1 — Policy state machine + `InvalidPolicyStateException`

- **ID:** E5-S1
- **Epic:** E5 — Policy issuance & lifecycle
- **Layer:** Domain
- **Group:** S3-A
- **Sprint:** 3
- **Depends on:** —
- **Traces:** AC-10

## Description

Implement the pure policy lifecycle state machine in `src/domain/policy_state_machine.py` and the typed
`InvalidPolicyStateException` in `src/types/errors.py`. Every service that changes `Policy.status`
(issuance, endorsement, renewal, lapse, cancellation) must call this function, so the allowed transitions
from `docs/conventions.md` are enforced in exactly one place. The module is pure: no I/O, logging or clock.

## Acceptance Criteria

1. [AC-10] `transition(current, target)` returns `target` for exactly the 8 allowed pairs: `ACTIVE → ENDORSED | LAPSED | CANCELLED | RENEWED` and `ENDORSED → ENDORSED | LAPSED | CANCELLED | RENEWED` _(category: functional)_
   - Verify: parametrise a test over the 8 allowed `(PolicyStatus, PolicyStatus)` pairs; assert each call returns the target status; assert no exception is raised
2. [AC-10] The remaining 17 of the 25 `PolicyStatus` pairs (e.g. `LAPSED → ACTIVE`, `CANCELLED → ENDORSED`, `RENEWED → CANCELLED`, `ACTIVE → ACTIVE`) raise `InvalidPolicyStateException` _(category: functional)_
   - Verify: parametrise a test over all 25 pairs minus the 8 allowed ones; assert `pytest.raises(InvalidPolicyStateException)` for each; assert the count of rejected pairs is 17
3. [AC-10] `InvalidPolicyStateException` carries `current_status` and `target_status` attributes and its message names both, e.g. `"Invalid policy transition CANCELLED -> ENDORSED"` _(category: functional)_
   - Verify: call `transition(PolicyStatus.CANCELLED, PolicyStatus.ENDORSED)` inside `pytest.raises`; assert `exc.current_status == PolicyStatus.CANCELLED` and `exc.target_status == PolicyStatus.ENDORSED`; assert both names appear in `str(exc)`
4. [—] `LAPSED`, `CANCELLED` and `RENEWED` are reported as terminal by `is_terminal(status)`, and `allowed_targets(status)` returns an empty set for them _(category: functional)_
   - Verify: assert `is_terminal` is `True` for the 3 terminal statuses and `False` for `ACTIVE`, `ENDORSED`; assert `allowed_targets(PolicyStatus.LAPSED) == frozenset()`
5. [—] `src/domain/policy_state_machine.py` imports only from `src.types` and the standard library (no `src.lib`, no `datetime.now`, no logging) _(category: integration)_
   - Verify: run `uv run lint-imports` and `backend/tests/architecture/`; assert both pass; grep the module for `logging`, `now(` and `src.lib` and assert zero matches
