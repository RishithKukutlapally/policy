# E3-S2 — Quote service + `Quote` persistence

- **ID:** E3-S2
- **Epic:** E3 — Quote engine
- **Layer:** Service
- **Group:** S2-B
- **Sprint:** 2
- **Depends on:** E3-S1, E2-S3
- **Traces:** AC-01, AC-12, AC-13, NFR-01

## Description

`src/service/quote_service.py` validates quote input, resolves the product's active PUBLISHED rule version,
calls the pure premium calculator and persists a `Quote` (`quotes` table via `quote_repository.py`) that records
product, rule version, the normalised input and the premium. It never falls back to another version, and it
can re-price a stored quote on its recorded version to prove reproducibility.

## Acceptance Criteria

1. [AC-01] `create_quote(actor, MOTOR, {owner_age: 30, sum_insured: "500000.00", vehicle_age_years: 3, engine_cc: 1200, zone: "A", ncb_percent: "20"})` persists a `quotes` row and returns premium `Decimal("14322.00")`, `rule_version` 1, `currency` `INR` and a UUID `quote_id` _(category: functional)_
   - Verify: seed the v1 rule versions; call `create_quote`; assert the returned values; read the row back and assert `premium` column equals `14322.00` and `rule_version == 1`
2. [AC-12] Invalid input raises `QuoteValidationError` carrying field-level errors and persists nothing: missing `sum_insured` → `{field: "sum_insured", code: "REQUIRED"}`; MOTOR sum_insured `50000.00` → `{field: "sum_insured", code: "OUT_OF_RANGE"}`; TERM_LIFE age 17 → `{field: "age", code: "OUT_OF_RANGE"}`; TERM_LIFE term_years 31 → `{field: "term_years", code: "OUT_OF_RANGE"}` _(category: functional)_
   - Verify: call `create_quote` with each invalid input; assert `QuoteValidationError.errors` contains the exact field/code pair; assert the `quotes` row count is unchanged
3. [AC-12] If the product has no PUBLISHED version (e.g. an empty `rule_set_versions` for HOUSEHOLD), `create_quote` raises `NoPublishedVersionError("HOUSEHOLD")` and persists nothing — no fallback to a DRAFT or to a file on disk _(category: functional)_
   - Verify: seed only MOTOR and TERM_LIFE; call `create_quote` for HOUSEHOLD; assert `NoPublishedVersionError`; add a HOUSEHOLD v1 DRAFT row only and assert the same error and zero quotes
4. [AC-13] `reprice(quote_id)` recomputes the premium from the quote's stored `inputs` on its recorded `rule_version` and returns exactly the stored premium even after a newer version is published: after MOTOR v2 (base_rate `"0.0320"`) is published, repricing the v1 quote still returns `14322.00` while a new quote with the same input returns `14784.00` on v2 _(category: functional)_
   - Verify: create the golden MOTOR quote on v1; publish a MOTOR v2 with base_rate 0.0320; call `reprice(quote_id)` and assert `14322.00` with version 1; call `create_quote` again and assert `14784.00` with version 2
5. [AC-13] The `quotes` table (new Alembic revision) stores `id`, `product`, `rule_version`, `inputs` (JSON), `sum_insured` `Numeric(12,2)`, `premium` `Numeric(12,2)`, `actor_id`, `created_at`, and the ORM maps money columns to `Decimal` _(category: integration)_
   - Verify: run `alembic upgrade head`; inspect column types; insert via the repository and read back; assert `type(row.premium) is Decimal`
6. [AC-01] Quote creation completes in under 2 s p95 over 50 sequential calls on the seeded SQLite DB _(category: performance)_
   - Verify: time 50 `create_quote` calls for rotating products; compute the 95th percentile; assert < 2.0 s
