# /knowledge-deposit — Encode a Recurring Mistake

Argument: `$ARGUMENTS` = one-line mistake summary (e.g. `"used Decimal(0.1) from float in refund calc"`).

## Step 1: Gather facts
- Search for prior occurrences: `grep -niE "<keywords>" docs/knowledge-deposits.md .claude/state/failures.md .claude/state/learned-rules.md docs/fix-loops/*.md`
- Identify the linked evidence: fix-loop doc, commit SHA, evaluator report, or hook log.
- State the root cause in one sentence (why the agent made it, not just what broke).

## Step 2: Choose the encoding (strongest that fits)

| Mistake type | Encode in | Example |
|---|---|---|
| Detectable in a diff at edit time | Hook `.claude/hooks/*.js` | extend `premium-precision-check.js` to block `Decimal(<float>)` |
| Structural / cross-file | Arch test via `archtest-author` skill | AST test for `round(` in money modules |
| Domain procedure the agent skipped | Project skill `.claude/skills/<name>/SKILL.md` | add `.xx5` cases to `premium-calc-evaluator` |
| Folder-scoped convention | Nearest `CLAUDE.md` (root / backend / domain / tests) | "rule numbers are decimal strings" in `backend/policy_rules/CLAUDE.md` |
| General agent lesson | `.claude/state/learned-rules.md` | append-only rule entry |

Prefer an automated guard (hook / test) over prose. Architecture tests and production-code changes are
generated by agents — delegate them; substrate files (hooks, skills, CLAUDE.md) may be edited directly.

## Step 3: Make the encoding change
Apply the change on a branch `docs/kd-<slug>` (or the current fix branch). Verify it bites:
- hook → feed it a violating sample and confirm it blocks;
- test → confirm it fails on a synthetic violation and passes on `main`;
- skill / CLAUDE.md → quote the added lines.

## Step 4: Append the deposit
Append one row at the bottom of the existing table in `docs/knowledge-deposits.md` (never rewrite earlier
rows). Use its exact 6-column schema — no extra columns, so the table stays valid:
```markdown
| ID | Date | Mistake / trap | Root cause | Encoded in | Evidence |
|----|------|----------------|------------|------------|----------|
| KD-006 | 2026-09-29 | `Decimal(0.1)` built from a float in refund calc | Agent copied a float literal from rule JSON | Hook `premium-precision-check.js` (blocks `Decimal(<float>)`); `backend/policy_rules/CLAUDE.md` | `docs/fix-loops/2026-09-29-refund-float.md`, `a1b2c3d` |
```
`ID` is `KD-NNN`, zero-padded, next after the last row. Put the guard type (hook / arch test / skill / rule) in
`Encoded in`. Only the row is appended; the header already exists.

## Step 5: Commit
```
docs(kd): <mistake summary>

Intent: prevent recurrence of <mistake>
Why: seen <n> times (<links>)
Acceptance: <guard> blocks a violating sample
Out of scope: fixing existing occurrences (tracked in <link>)
```
Merge via PR with `git merge --no-ff`. Print the new row and the files changed.
